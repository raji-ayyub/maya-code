# Maya's JavaScript Adventure

A small browser game for learning JavaScript. Write code to guide Maya to the flag, then use each level to practice commands, loops, and variables.

## Run locally

Requirements: Node.js 20 or newer and npm.

```powershell
cd frontend
npm install
npm run dev
```

Open the local URL printed by Next.js (usually http://localhost:3000).

To create and run a production build:

```powershell
npm run build
npm start
```
